# RDP-AutoUpdater
This is a python based auto updater relying on RDPWrapOffsetFinder.

To setup, just put the files in somewhere you will remember and make a task schedule on login ( for the main user you rdp **FROM** )

This project uses a slightly modified version of RBTray too, mainly so you can right click while shifting the top of a rdp window to put it into your tray

repositories used: 
https://github.com/llccd/RDPWrapOffsetFinder 
https://github.com/benbuck/rbtray
